## Тексеру нәтижелері

- `npm.cmd test` — **51/51 өтті**, соның ішінде қате телефон түрлері және баяу сұраудағы сессияны қайтару сынақтары. Жаңа сервер сынақтары түзетуге дейін ақауларды қайталады: 400 орнына 500, 401 орнына 200 қайтты; түзетуден кейін өтті.
- `npm.cmd run lint` — өтті.
- `npm.cmd run build` — өтті; дайын сайт `dist` бумасына жиналды.
- `npm.cmd audit --json` — белгілі осалдық **0**.
- `npm.cmd run test:ticket-browser` — Chrome арқылы кеңейтілген сценарий өтті, JavaScript орындалу қатесі **0**.
- Негізгі SQLite базасы тек оқу режимінде тексерілді: `PRAGMA quick_check` — `ok`, `foreign_key_check` — қате **0**.

Браузер сынағы аккаунтсыз жазылуды, бос уақыттарды қайта жүктеуді, телефонды автоматты толтыруды, мәтін валидациясын, PNG ішіндегі QR кодты декодтауды, QR және қолмен талон ашуды, PDF шығаруды, сәтсіз бас тартудан кейін талонның сақталуын, сәтті бас тартуды, өткен қабылдаудан бас тартуды жасыруды тексереді.

Әкімші сілтемесі, кейін қызметкер тіркеу, авторизациядағы форманы бұғаттау, жаңа бөлім формасын тазарту, әкімшінің бес бөлімі, қызметкердің жабық бөлімге рұқсаты, сүзгі жауаптары мен қателерінің кері ретпен келуі, CSV жүктеуді күту және аккаунттан шығу да қамтылды. Негізгі беттер 320, 375, 768 және 1366 px ендерінде көлденең тасуға тексерілді.

Сынақ аккаунттары мен жазылулар жадтағы бөлек дерекқорда жасалды. Негізгі аккаунттар, құпиясөздер және азаматтардың жазылулары өзгертілмеді. Браузер артефактілері: `.tmp/ticket-qr-review`.

Өзгертілгенге дейінгі бастапқы код көшірмесі: `.backups/qa-source-2026-11-16-150801`. Бұл буманың SQLite базасының көшірмесі емес екенін ескеріңіз.

## Тексеру шекарасы

Бұл нәтиже осы компьютердегі нұсқаға қатысты. Нақты хостинг, сыртқы туннельдің ағымдағы қолжетімділігі, Safari/Firefox және физикалық телефон тексерілмеді. Мерекелік күндер, SMS, ЭЦҚ, eGov және файл тіркеу бұрынғыдай іске асырылмаған мүмкіндіктер болып қалады.

Дайын нұсқаны іске қосу: `npm.cmd start`. Бұрын іске қосылған Node API түзетулерді қолдануы үшін оны қайта іске қосу қажет. Сайт сыртқы хостингке жарияланған жоқ.
