# 2026-11-12 тексеру есебі

Жергілікті бастапқы код, Node API және дайын React интерфейсі тексерілді. Браузер сынақтары жадтағы бөлек SQLite базасын қолданады; негізгі базадағы аккаунттар мен жазылулар өзгертілмейді.

## Түзетілген ақаулар

- Жинау іске қосылмады: орнатылған TypeScript пакетінің `_tsc.js` файлы жетіспеді. Пакеттер lockfile бойынша қайта орнатылды.
- Қызметкер жабық бөлімнің бұрынғы қабылдауларын бөлім бойынша сүзе алмады. Авторизацияланған `/api/staff/departments` қызметкерге өзіне бекітілген ашық және жабық бөлімдерді қайтарады; азаматтарға тек ашық бөлімдер көрсетіледі.
- Сүзгілер тез ауысқанда ескі HTTP жауап жаңа тізімді алмастыра алатын. Жаңарту нұсқасы тек соңғы жауапты қолданады; кабинет жабылғанда алдыңғы жаңарту жарамсыз болады.
- Ұйым баптауларының рұқсат етілген ұзын қазақша мәтіні 16 KB сұрау шегіне сыймады. Шек 64 KB болды; әр өрістің серверлік шегі интерфейспен сәйкестендірілді. Екі шектің де тексеруі сақталған.
- Бос уақыттарды жүктеу қатесінен кейін сол күннің кестесін қайта сұрату батырмасы болмады. «Уақыттарды қайта жүктеу» қосылды; өтінімнің толтырылған өрістері сақталады.
- Бас тарту сұрауы сәтсіз болса, ашық талон жоғалатын. Енді талон көрініп тұрады және сұрауды қайталауға болады.
- Өтіп кеткен қабылдауға бас тарту ұсынылатын. Интерфейс уақытты ескереді; сервердегі уақыт тексеруі сақталған.
- «Негізгі мазмұнға өту» басқа беттен басты бетке ауыстыратын. Енді ағымдағы беттегі main элементіне фокус береді.
- Тар экранда мәзірдің соңғы сілтемелері көлденең айналдырудың артында қалатын. Мәзір жолдарға бөлінді; body-дің минимал енінен пайда болған тасу жойылды.
- PORT өзгергенде әзірлеу proxy-і бұрынғы 3001 портына сұрау жіберетін. Енді PORT орта айнымалысынан немесе .env файлынан оқылады.
- ESLint уақытша Chrome профильдері мен қалпына келтіру көшірмелерін аралап, тексеруді созатын. Деректер мен уақытша бумалар тексеруден шығарылды.
- npm audit көрсеткен 10 moderate ескерту minimatch тәуелділігіне байланысты болды. Override арқылы түзетілген 11.0.1 немесе үйлесімді 11.x нұсқасы қолданылады. [Осалдық сипаттамасы](https://github.com/advisories/GHSA-g3hv-75wg-m249). Жаңартудан кейін lint және build өтті; аудит 0 осалдық көрсетті.
- Браузер сынағында ай ауысқанда күнтізбенің ескі CSS селекторы қолданылатын. Ағымдағы селекторға ауыстырылды.

## Тексерулер

`npm.cmd test` — 47/47 өтті. Рұқсаттар, қосарланған жазылудан қорғау, кесте, уақыт белдеуі, талон құпиялығы, көшірулер, HTTP және API қателері қамтылады. Жабық бөлімдерді сүзу және максимал қазақша баптауларға регрессиялық тексерулер қосылды.

`npm.cmd run lint` және `npm.cmd run build` — өтті. `npm.cmd audit --json` — 0 осалдық.

`npm.cmd run test:ticket-browser` Chrome арқылы мыналарды тексереді:

- Азаматтың аккаунтсыз жазылуы және кесте жүктелмегенде қайталау.
- PNG талонның QR кодын нақты декодтау, QR арқылы ашу, телефон және кодпен тексеру, PDF шығару.
- Сәтсіз бас тартудан кейін талонның сақталуы, сәтті бас тарту және өткен қабылдаудың шектеуі.
- Басты бет, нұсқаулық, байланыс, талон және кабинет беттері: 320, 375, 768, 1366 px. Тасу viewport-тың нақты clientWidth енімен салыстырылады.
- Негізгі мазмұнға өту, әкімшінің бес бөлімі, қызметкерге тек өз бөлімін көрсету, жабық бөлімді сүзу, реті ауысқан жауаптар және аккаунттан шығу.

Артефактілер: `.tmp/ticket-qr-review` — экран суреттері, PNG талон және receipt.pdf. Олар сынақ деректерін қамтиды.

## Қалған шектеулер

Бұл тексеру нақты хостинг, сыртқы туннельдің қазіргі қолжетімділігі, Safari/Firefox немесе физикалық телефонды қамтымайды. Ұйымның нақты деректері мен жұмыс кестелерін әкімші толтырады. Мерекелік күндер, SMS, ЭЦҚ, eGov және файл тіркеу бұрынғыдай іске асырылмаған мүмкіндіктер болып қалады.

Қолмен тексеру: `npm.cmd run dev`, одан кейін http://127.0.0.1:5173. Дайын сайт: `npm.cmd start`, http://127.0.0.1:3001. Өзгертілген API коды қолданылуы үшін бұрын ашылған серверді қайта іске қосу қажет.
